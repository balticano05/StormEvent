# Ошибки 37–70: Проблемы с контентом

Alert при смене формата: `parse.errors > 10/мин`. Логи с request-id — можно отследить конкретный запрос.

### Ошибка 37. HTML-структура изменилась
Atlas обновил вёрстку. Селекторы Jsoup не находят элементов. `ParseException: 0 rides found`.
Tool возвращает пустой. Alert — нужно обновить парсер.

### Ошибка 38. HTML валиден, но поля переименованы
Класс `.ride-price` стал `.ride-cost`. Парсер находит rides, но `price=null`.
Валидатор `OfferNormalizer` отбрасывает. Tool возвращает пустой.

### Ошибка 39. HTML с новыми обязательными полями
Источник добавил CAPTCHA-токен в форму. Парсер не отправляет токен. 403. Circuit OPEN.

### Ошибка 40. Кодировка не UTF-8
Atlas вернул Windows-1251. Jsoup по умолчанию UTF-8 → кракозябры.
**Fix:** `Jsoup.parse(body, charsetFromHeader, baseUri)`.

### Ошибка 41. Кодировка указана неверно
Meta-тег `charset=windows-1251`, но реально UTF-8. Парсер доверяет meta → кракозябры.
**Fix:** override charset.

### Ошибка 42. BOM в начале ответа
UTF-8 BOM перед JSON. Jackson 3 не парсит. **Fix:** strip BOM.

### Ошибка 43. JSON с trailing comma
Atlas вернул `{"rides": [...],}`. Jackson 3 strict → ошибка.
**Fix:** `JsonReadFeature.ALLOW_TRAILING_COMMA`.

### Ошибка 44. JSON с одинарными кавычками
`{'rides': [...]}`. Jackson strict → ошибка.
**Fix:** `JsonReadFeature.ALLOW_SINGLE_QUOTES`.

### Ошибка 45. JSON с NaN/Infinity
Atlas вернул `price: NaN`. Jackson strict → ошибка.
**Fix:** `JsonReadFeature.ALLOW_NON_NUMERIC_NUMBERS`.

### Ошибка 46. JSON с комментариями
Atlas вернул `{/* comment */ "rides": [...]}`. Jackson strict → ошибка.
**Fix:** `JsonReadFeature.ALLOW_JAVA_COMMENTS`.

### Ошибка 47. JSON с неэкранированными символами
Atlas вернул `{"name": "Минск "Столица""}`. Jackson strict → ошибка.
**Fix:** `JsonReadFeature.ALLOW_UNESCAPED_CONTROL_CHARS`.

### Ошибка 48. JSON с null в обязательном поле
Atlas вернул `from: null`. Парсер создаёт `AtlasRide` с null. Валидатор отбрасывает. Остальные проходят.

### Ошибка 49. JSON с числом вместо строки
`price: "25.50"` вместо `25.50`. Jackson маппит через `@JsonDeserialize`.
Если не настроено — `MismatchedInputException`.

### Ошибка 50. JSON с датой в неожиданном формате
`departTime: "15/06/2025 08:20"`. `DateTimeFormatter` не парсит. Парсер кидает `DateTimeParseException`. Ride пропускается.

### Ошибка 51. JSON с датой в Unix timestamp
`departTime: 1718430000`. Ожидалась строка. **Fix:** кастомный десериализатор.

### Ошибка 52. HTML с невалидной структурой
Незакрытые теги, вложенность сломана. Jsoup исправляет, но селекторы могут не сработать.

### Ошибка 53. HTML с JS-рендерингом
Atlas отдаёт SPA с пустым `<div id="app">`, данные грузятся через JS. Jsoup видит пустоту.
**Fix:** использовать API вместо HTML или headless-браузер.

### Ошибка 54. HTML с зашифрованными данными
Цены закодированы в base64 или JS-обфускации. Парсер не может декодировать.
**Fix:** реверс-инжиниринг или отказ от источника.

### Ошибка 55. HTML с бесконечной прокруткой
Первая страница — 10 рейсов, остальные через AJAX. Парсер видит только 10.
**Fix:** эмулировать пагинацию.

### Ошибка 56. HTML с lazy-loading изображений
Данные в `data-src`, не в `src`. Парсер ищет в `src` — пусто. **Fix:** читать `data-*`.

### Ошибка 57. HTML с тенями (shadow DOM)
Jsoup не видит shadow DOM. Парсер пустой. **Fix:** headless-браузер.

### Ошибка 58. HTML с iframe
Данные внутри iframe. Jsoup не следует. **Fix:** отдельный запрос к iframe URL.

### Ошибка 59. HTML с мусорными комментариями
Внутри HTML — тысячи комментариев, парсер тормозит.
**Fix:** `Parser.xmlParser()` или отключить комментарии.

### Ошибка 60. HTML размером 50 МБ
Atlas отдал гигантскую страницу. Jsoup грузит в память. OOM. **Fix:** лимит на размер ответа.

### Ошибка 61. HTML с дубликатами
Один и тот же ride в двух блоках. Парсер возвращает дубликат. Combiner дедуплицирует по `rideId`.

### Ошибка 62. HTML с пустыми обязательными полями
`<span class="price"></span>`. Парсер возвращает `price=null`. Валидатор отбрасывает.

### Ошибка 63. HTML с ценой в другой валюте
Atlas вернул цену в USD вместо BYN. Парсер сохраняет как есть. Combiner конвертирует или помечает.

### Ошибка 64. HTML с ценой без валюты
`price: "25"` без указания. Парсер предполагает BYN. Может быть неверно.

### Ошибка 65. HTML с ценой в виде диапазона
`price: "от 25 BYN"`. Парсер парсит 25, но теряет «от». **Fix:** regex на диапазон.

### Ошибка 66. HTML с временем в 12-часовом формате
`08:20 PM`. Парсер ожидает 24-часовой. **Fix:** `DateTimeFormatter` с AM/PM.

### Ошибка 67. HTML с датой в локали
`15 июня 2025`. Парсер ожидает ISO. **Fix:** русская локаль.

### Ошибка 68. HTML с относительной датой
`завтра`, `через 2 дня`. Парсер не может вычислить. **Fix:** NLP или отказ.

### Ошибка 69. HTML с часовым поясом
`08:20 MSK`. Парсер игнорирует TZ. **Fix:** парсить TZ.

### Ошибка 70. HTML с координатами в разных форматах
`51.5, 30.5` vs `51°30'N 30°30'E`. Парсер ожидает один. **Fix:** оба формата.
