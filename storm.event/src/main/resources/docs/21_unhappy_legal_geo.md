# Ошибки 201–235: Юридические/этические и специфика РБ/РФ

Fallback: кэш, частичные результаты, понятное сообщение пользователю. Ни один анхэппи путь не должен ронять всю сессию.

## Юридические и этические (201–220)

### Ошибка 201. Источник запретил парсинг в robots.txt
Atlas добавил `Disallow: /api/`. Парсер нарушает. **Fix:** уважать robots.txt или отказ.

### Ошибка 202. Источник прислал Cease & Desist
Юридическое письмо. **Fix:** отключить источник.

### Ошибка 203. Источник добавил ToS-баннер
«Использование API запрещено». Парсер видит баннер. **Fix:** отказ.

### Ошибка 204. Источник логирует наши запросы
User-Agent виден в логах. Если UA выдаёт бота — бан. **Fix:** реалистичный UA.

### Ошибка 205. Источник добавил honeypot
Скрытая ссылка, которую бот следует. Бан. **Fix:** игнорировать скрытые элементы.

### Ошибка 206. Источник добавил fingerprinting
JS проверяет canvas, WebGL. OkHttp не выполняет JS. Бан.
**Fix:** headless с реалистичным fingerprint.

### Ошибка 207. Источник добавил rate limit по IP
100 запросов/час. **Fix:** прокси-ротация.

### Ошибка 208. Источник добавил rate limit по API-ключу
Если ключ есть. **Fix:** запрос ключа.

### Ошибка 209. Источник добавил обязательную авторизацию
Только для зарегистрированных. **Fix:** регистрация.

### Ошибка 210. Источник добавил платный API
Бесплатный доступ закрыт. **Fix:** оплата или отказ.

### Ошибка 211. Источник добавил GDPR-баннер
Требует согласия на cookies. Парсер игнорирует. Может нарушить.

### Ошибка 212. Источник добавил age verification
Требует подтверждения 18+. Парсер игнорирует.

### Ошибка 213. Источник добавил гео-блокировку
Доступ только из РБ. Наш сервер в другой стране. 403. **Fix:** прокси в РБ.

### Ошибка 214. Источник добавил VPN-блокировку
Определяет VPN. 403. **Fix:** residential proxy.

### Ошибка 215. Источник добавил бан по User-Agent
`okhttp/5.5.0` в UA — бан. **Fix:** реалистичный UA.

### Ошибка 216. Источник добавил бан по заголовкам
Отсутствие `Accept-Language` — бан. **Fix:** полный набор заголовков.

### Ошибка 217. Источник добавил бан по TLS fingerprint
JA3 fingerprint OkHttp отличается от Chrome. Бан. **Fix:** uTLS или curl-impersonate.

### Ошибка 218. Источник добавил бан по HTTP/2 fingerprint
OkHttp шлёт свои настройки. Бан. **Fix:** имитация Chrome.

### Ошибка 219. Источник добавил бан по поведению
Слишком быстрые запросы. **Fix:** throttle.

### Ошибка 220. Источник добавил бан по сессии
Одна сессия, много запросов. **Fix:** ротация сессий.

## Специфика РБ/РФ (221–235)

### Ошибка 221. BZD не работает на маршрутах внутри РФ
Внутренние рейсы РФ — не через BZD. **Fix:** РЖД API (если доступно).

### Ошибка 222. Atlas не работает на маршрутах внутри РФ
Atlas — белорусский. **Fix:** российские агрегаторы.

### Ошибка 223. TicketBus не работает на маршрутах внутри РФ
Аналогично.

### Ошибка 224. Санкции блокируют оплату
Карта РФ не принимается на белорусских сайтах. Агент не отвечает за оплату. Дисклеймер.

### Ошибка 225. Санкции блокируют доступ к сайту
Российский IP не может зайти на белорусский сайт. 403. **Fix:** прокси.

### Ошибка 226. Языковой барьер
Сайт только на белорусском. **Fix:** маппинг.

### Ошибка 227. Валюта
BYN vs RUB vs USD. **Fix:** конвертация или явное указание.

### Ошибка 228. Часовой пояс
Europe/Minsk vs Europe/Moscow. **Fix:** явно указать TZ.

### Ошибка 229. Праздники
Расписание меняется в праздники. **Fix:** учитывать.

### Ошибка 230. Погода
Рейсы отменяются из-за погоды. Источник возвращает 0. Легитимно.

### Ошибка 231. Забастовка
Рейсы отменены. Источник возвращает 0.

### Ошибка 232. Ремонт дорог
Рейсы перенаправлены. Источник возвращает другие маршруты.

### Ошибка 233. Граница
Время на границе не учтено. **Fix:** добавлять буфер.

### Ошибка 234. Визы
Пользователь не знает про визы. **Fix:** дисклеймер.

### Ошибка 235. COVID-ограничения
Требования к тестам. **Fix:** дисклеймер.
