# Хэппи пути 18–28: События + транспорт, Отели + транспорт

## События + транспорт

### HP-18. Концерт в Минске, из Гомеля
«Концерт в Минске 20 июля, приеду из Гомеля». `EVENT+TRAIN`.
TicketPro находит концерт в Минск-Арене. BZD находит поезда Гомель→Минск.
Комбинер оставляет те, что приходят за **≥2 часа** до начала.
**Ответ:** «Концерт X, 19:00 → поезд 715Б 14:30→17:50». Две ссылки.

### HP-19. Концерт, из Бреста
«Концерт в Минске 15 августа, из Бреста». TicketPro + BZD.
Поезд прибывает за 2 часа. Ссылки.

### HP-21. Однодневная поездка на событие
«Что-нибудь в Бресте 12 июля, из Минска на один день». `EVENT+BUS`, `dayTrip=true`.
Событие + автобусы туда и обратно. Две-три ссылки.

### HP-22. Концерт в Москве, из Минска
«Концерт в Москве 5 сентября, приеду из Минска». `EVENT+TRAIN`.
BZD даёт 002Б (ночной). TicketPro даёт билеты. Две ссылки.

### HP-23. Событие рядом с отелем
«Еду на концерт в Минск 20 июля, нужен отель рядом с площадкой». `EVENT+HOTEL`, `nearVenue=true`.
TicketPro вытаскивает venue из деталей, BelHotel ищет отели в радиусе 2 км. Комбо.

## Отели + транспорт

### HP-24. Брест с ночёвкой
«Брест на выходные из Минска, отель на 1 ночь, 2 человека». `BUS+HOTEL`.
Atlas + BelHotel. 4 комбо «автобус + отель», от 120 BYN. Восемь ссылок.

### HP-25. Гродно, отель в центре
«Гродно 2 ночи, отель в центре, из Минска». `prefs={hotelCenter=true}`.
Atlas + TicketBus + BelHotel. Три комбо.

### HP-26. Санаторий
«Санаторий под Минском на неделю, июль, для двоих». `HOTEL+BUS`, `to=Нарочь`.
BelHotel возвращает санатории, Atlas — трансфер. Три варианта, ссылки на belhotel.by.

### HP-27. Москва + отель, поездом
«Поездом в Москву на 3 дня, отель, 10–13 июля». `TRAIN+HOTEL`.
BZD + BelHotel. Поезд + три отеля, комбо.

### HP-28. Отель 4 звезды
«Романтические выходные в Гродно из Минска, отель получше». `BUS+HOTEL`, `hotelRating>=4`.
Atlas + BelHotel. Три комбо с отелями 4*.
