# Ошибки 71–120: Специфика AtlasBus и BZD

## Специфика AtlasBus (71–86)

### Ошибка 71. Atlas SSE возвращает событие progress без изменений
Atlas шлёт `progress: 50%` каждые 100 мс. Парсер обрабатывает 100 событий. Tool логирует только последнее.

### Ошибка 72. Atlas SSE возвращает error в середине потока
Atlas нашёл 5 rides, потом ошибка. Парсер сохраняет 5 rides + error.
Tool возвращает 5 rides с пометкой `partial=true`.

### Ошибка 73. Atlas SSE не присылает done
Поток закрылся без done. Парсер возвращает `partial=true`. Tool логирует.

### Ошибка 74. Atlas suggest возвращает пустой список
Город не найден. Tool возвращает пустой. Clarifier: «Город не найден, уточните название».

### Ошибка 75. Atlas suggest возвращает 100 городов
Неоднозначный запрос. Tool берёт топ-5. Clarifier: «Уточните: Минск, Минск-Восточный, ...?»

### Ошибка 76. Atlas требует User-Agent
Без UA — 403. Constants содержит UA. Если UA устарел — 403. **Fix:** обновить UA.

### Ошибка 77. Atlas требует Referer
Без Referer — 403. Constants содержит Referer. **Fix:** обновить.

### Ошибка 78. Atlas требует X-Requested-With
Без заголовка — 403. Constants содержит. Fix.

### Ошибка 79. Atlas добавил CSRF-токен
Все POST требуют токен из HTML. Парсер не знает. **Fix:** warmup + extract token.

### Ошибка 80. Atlas добавил Cloudflare
Запросы возвращают JS-challenge. OkHttp не выполняет JS. 403. **Fix:** headless-браузер или отказ.

### Ошибка 81. Atlas вернул HTML вместо SSE
Ошибка на их стороне. Парсер SSE видит HTML. `SseParseException`. Tool возвращает пустой.

### Ошибка 82. Atlas SSE с нестандартным разделителем
`\r\n` вместо `\n`. Парсер SSE должен поддерживать оба.

### Ошибка 83. Atlas SSE с BOM
Первый event начинается с BOM. Парсер strip BOM.

### Ошибка 84. Atlas SSE с комментариями
`: comment` в потоке. Парсер игнорирует строки, начинающиеся с `:`.

### Ошибка 85. Atlas SSE с retry-директивой
`retry: 3000`. Парсер игнорирует (или использует для reconnect).

### Ошибка 86. Atlas SSE с id
`id: 123`. Парсер сохраняет для reconnect.

## Специфика BZD / pass.rw.by (87–120)

### Ошибка 87. BZD warmup не сработал
`GET /ru/` вернул 200, но cookie не сохранился. Последующий запрос — 403.
**Fix:** проверить cookie-jar.

### Ошибка 88. BZD cookie протух
Сессия истекла через 30 мин. Запрос — 403. **Fix:** retry warmup.

### Ошибка 89. BZD cookie привязан к IP
Смена IP → 403. **Fix:** sticky session или прокси.

### Ошибка 90. BZD cookie привязан к User-Agent
Смена UA → 403. **Fix:** консистентный UA.

### Ошибка 91. BZD требует JSESSIONID
Warmup создаёт JSESSIONID. Без него — 403.

### Ошибка 92. BZD требует _ga cookie
Analytics-cookie обязателен. Warmup создаёт через JS. OkHttp не выполняет JS. **Fix:** headless или отказ.

### Ошибка 93. BZD ESR-код станции не найден
`from_esr=9999999` не существует. BZD возвращает пустой результат.
Clarifier: «Станция не найдена».

### Ошибка 94. BZD возвращает несколько станций с одним именем
Минск → 3 станции (Минск-Пассажирский, Минск-Восточный, Минск-Северный).
Clarifier: «Уточните станцию».

### Ошибка 95. BZD требует точный ESR
Минск без ESR → 400. **Fix:** resolve через suggest.

### Ошибка 96. BZD front_date в неверном формате
`2025-06-15` вместо `15.06.2025`. BZD возвращает пустой результат.

### Ошибка 97. BZD front_date в прошлом
BZD возвращает пустой. Валидатор ловит раньше.

### Ошибка 98. BZD front_date > 90 дней вперёд
BZD не продаёт так далеко. Пустой результат.
Clarifier: «Билеты продаются за 90 дней».

### Ошибка 99. BZD вернул HTML с капчей
Cloudflare или собственная капча. Парсер видит форму. `CaptchaException`. Circuit OPEN.

### Ошибка 100. BZD вернул HTML с ошибкой
`<div class="error">Поездов не найдено</div>`. Парсер не находит rides. Tool возвращает пустой.
Это легитимно — не ошибка.

### Ошибка 101. BZD вернул HTML с редиректом на главную
Сессия сломалась. Парсер видит главную страницу. `ParseException: 0 rides found`. Tool retry warmup.

### Ошибка 102. BZD вернул HTML с изменённой вёрсткой
Селекторы `.route-item` не находят. `ParseException`. Alert.

### Ошибка 103. BZD вернул HTML с ценами в BYN и RUB
Двойные цены. Парсер берёт первую. Может быть неверно.

### Ошибка 104. BZD вернул HTML с местами, но без цен
Цены грузятся через AJAX. Парсер видит места, но `price=null`.
**Fix:** отдельный запрос за ценами.

### Ошибка 105. BZD вернул HTML с поездами, но без мест
Все места проданы. `seats: 0`. Парсер сохраняет, Combiner отбрасывает.

### Ошибка 106. BZD вернул HTML с поездами, но без времени
Время в JS. Парсер видит `--:--`. **Fix:** AJAX.

### Ошибка 107. BZD вернул HTML с относительными датами
`сегодня`, `завтра`. Парсер не может вычислить.

### Ошибка 108. BZD вернул HTML с датами в местном времени
BZD использует Europe/Minsk. Парсер сохраняет без TZ. **Fix:** явно указать TZ.

### Ошибка 109. BZD вернул HTML с ценой в копейках
`price: 2500` = 25.00 BYN. Парсер сохраняет как 2500. **Fix:** делить на 100.

### Ошибка 110. BZD вернул HTML с ценой без копеек
`price: 25` = 25.00 BYN. Парсер сохраняет как 25. OK.

### Ошибка 111. BZD вернул HTML с несколькими классами обслуживания
Плацкарт, купе, СВ. Парсер берёт только первый. **Fix:** парсить все.

### Ошибка 112. BZD вернул HTML с поездами, но без номера
`number: null`. Валидатор отбрасывает.

### Ошибка 113. BZD вернул HTML с поездами, но без перевозчика
`carrier: null`. Парсер сохраняет с null.

### Ошибка 114. BZD вернул HTML с дубликатами
Один и тот же поезд дважды. Combiner дедуплицирует.

### Ошибка 115. BZD вернул HTML с 0 результатов, но 200
Легитимно. Tool возвращает пустой.

### Ошибка 116. BZD вернул HTML с 1000 результатов
Парсер тормозит. **Fix:** пагинация или лимит.

### Ошибка 117. BZD вернул HTML с невалидным UTF-8
Кракозябры. **Fix:** charset detection.

### Ошибка 118. BZD вернул HTML с BOM
Jsoup strip BOM.

### Ошибка 119. BZD вернул HTML с комментариями внутри тегов
`<div class="route"><!-- -->...`. Jsoup игнорирует комментарии.

### Ошибка 120. BZD вернул HTML с `<script>` с данными
Данные в JS-переменной. Jsoup видит только HTML. **Fix:** regex или JS-парсер.
