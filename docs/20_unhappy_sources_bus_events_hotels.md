# Ошибки 121–200: Специфика TicketBus, TicketPro, BelHotel

## Специфика TicketBus (121–150)

### Ошибка 121. TicketBus warmup не сработал
`GET /` вернул 200, cookie не сохранился. 403. **Fix:** retry.

### Ошибка 122. TicketBus требует Referer
Без Referer — 403. Constants содержит.

### Ошибка 123. TicketBus требует X-CSRF-Token
Все POST требуют. Warmup извлекает токен. Если нет — 403.

### Ошибка 124. TicketBus вернул HTML с капчей
reCAPTCHA. `CaptchaException`. Circuit OPEN.

### Ошибка 125. TicketBus вернул HTML с изменённой вёрсткой
Селекторы не находят. `ParseException`. Alert.

### Ошибка 126. TicketBus вернул HTML с пустым расписанием
Легитимно. Tool возвращает пустой.

### Ошибка 127. TicketBus вернул HTML с расписанием, но без рейсов
Расписание есть, рейсы через AJAX. **Fix:** отдельный запрос.

### Ошибка 128. TicketBus вернул HTML с рейсами, но без цен
Цены через AJAX. Fix.

### Ошибка 129. TicketBus вернул HTML с ценами в BYN и RUB
Двойные. Парсер берёт первую.

### Ошибка 130. TicketBus вернул HTML с остановками без ID
ID через AJAX. Парсер не может resolve. Clarifier.

### Ошибка 131. TicketBus вернул HTML с остановками, но без координат
Координаты в JS. Парсер видит null.

### Ошибка 132. TicketBus вернул HTML с остановками в другом порядке
Сортировка по алфавиту vs по релевантности. Парсер сохраняет как есть.

### Ошибка 133. TicketBus вернул HTML с остановками с опечатками
Минск vs Мінск. Парсер сохраняет как есть. Combiner может не сматчить.

### Ошибка 134. TicketBus вернул HTML с остановками на белорусском
Мінск вместо Минск. **Fix:** транслитерация.

### Ошибка 135. TicketBus вернул HTML с остановками на английском
Minsk вместо Минск. **Fix:** маппинг.

### Ошибка 136. TicketBus вернул HTML с дубликатами остановок
Минск дважды. Combiner дедуплицирует.

### Ошибка 137. TicketBus вернул HTML с невалидными датами
`32.13.2025`. `DateTimeParseException`. Парсер пропускает.

### Ошибка 138. TicketBus вернул HTML с временем в прошлом
Рейс уже ушёл. Combiner отбрасывает.

### Ошибка 139. TicketBus вернул HTML с временем без даты
`08:20` без дня. Парсер предполагает сегодня.

### Ошибка 140. TicketBus вернул HTML с ценой в виде строки
`price: "25.50 BYN"`. Парсер regex.

### Ошибка 141. TicketBus вернул HTML с ценой в виде диапазона
`от 25 BYN`. Парсер берёт min.

### Ошибка 142. TicketBus вернул HTML с ценой без валюты
Предполагает BYN.

### Ошибка 143. TicketBus вернул HTML с рейсами, но без перевозчика
`carrier: null`. Парсер сохраняет.

### Ошибка 144. TicketBus вернул HTML с рейсами, но без типа автобуса
`busType: null`. Парсер сохраняет.

### Ошибка 145. TicketBus вернул HTML с рейсами, но без свободных мест
`seats: null`. Парсер сохраняет.

### Ошибка 146. TicketBus вернул HTML с 0 рейсов, но 200
Легитимно.

### Ошибка 147. TicketBus вернул HTML с 500 рейсами
Парсер тормозит. **Fix:** пагинация.

### Ошибка 148. TicketBus вернул HTML с невалидным UTF-8
Кракозябры.

### Ошибка 149. TicketBus вернул HTML с BOM
Strip BOM.

### Ошибка 150. TicketBus вернул HTML с JS-редиректом
`<script>window.location = '/error'</script>`. Jsoup не выполняет JS. Парсер видит 200 OK с редиректом.
**Fix:** headless.

### Ошибка 168. TicketPro вернул HTML с venue, но без координат
Combiner не может найти отель рядом. Clarifier: «Где именно?»

### Ошибка 169. TicketPro вернул HTML с venue на белорусском
Палац Спорту вместо Дворец Спорта. **Fix:** маппинг.

### Ошибка 170. TicketPro вернул HTML с venue, которого нет в BelHotel
Combiner не может связать. **Ответ:** «Отелей рядом не нашлось».
