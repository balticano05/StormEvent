# Известные ограничения MVP

- Валюты: курсы-затычки, без live-обновления (ADR-047).
- LLM: stub до появления ключа OpenRouter; реальные вызовы не проверены.
- Queue/circuit breaker/приоритеты — отменены (ADR-VL-15, ADR-VL-04).
- Единственный инстанс приложения; multi-node отложено (ADR-045).
- SSE/стриминг в публичный API не возвращается (ADR-VL-01): ответ — обычный текст.
- robots.txt не используется как гейт (ADR-VL-17); rate-limiter отложен.
- Health/ready не проверяют доступность внешних LLM/источников — только БД и схему.
