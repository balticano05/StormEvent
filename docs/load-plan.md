# Нагрузочный план

50 RPS сценарий (шаг 913): 1 поиск = `POST /api/v1/agent/chat` с текстом
«автобус Минск-Брест». Замеры: latency p50/p95, счётчики метрик, длительность одного вызова.

Команда прогона: локальный `wrk`/`hey`, таргет `http://localhost:8080/api/v1/agent/chat`,
длительность 60 с, 50 RPS. Live-источники в нагрузочном прогоне отключены
(репозиториям дать пустой `source_state.enabled=false`), чтобы не гонять
внешние API.

Образец замеров (на ноде с pg развёрнутого compose): зафиксировать в `docs/e2e-report.md`.
