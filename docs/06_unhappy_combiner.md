# Анхэппи пути 23–28: Проблемы комбинирования

Комбинер: склейка офферов в комбо (транспорт+отель, событие+транспорт, multi-city), контроль бюджета, стыковок и размеров.

### АНП-23. Ни один поезд не приходит вовремя на событие
`EVENT+TRAIN`: концерт 19:00, все поезда прибывают после 18:30.
Combiner отбрасывает все.
**Ответ:** «На этот концерт из Гомеля поездом не успеть. Показать автобусы?»

### АНП-24. Отель дороже бюджета
`BUS+HOTEL`, бюджет 200 BYN. Автобус 40 BYN + отель 180 BYN = 220 BYN.
Combiner отбрасывает все комбо.
**Ответ:** «В бюджет не укладывается. Ближайшее — 220 BYN».

### АНП-25. Нет отелей рядом с площадкой
`nearVenue=true`, но BelHotel вернул отели в 15 км.
Combiner помечает «рядом» как «далеко».
**Ответ:** «Отелей рядом нет, ближайший — 15 км».

### АНП-26. Multi-city: нет стыковки
Минск→Витебск 10:00, Витебск→Полоцк 09:00 (уже ушёл).
Combiner не может склеить цепочку.
**Ответ:** «Прямой маршрут не строится. Разбить на отдельные сегменты?»

### АНП-27. Декартово произведение слишком большое
`BUS (20) × HOTEL (30) = 600` комбо.
Combiner ограничивает top-50 по score до финального ранжирования.

### АНП-28. Combiner получил офферы только по одному домену
Запрос был `BUS+HOTEL`, но `HOTEL` упал.
Combiner не может строить комбо. **Fallback:** показывает только транспорт, в summary предупреждение.
