# Анхэппи пути 29–33: LLM на этапе summary

Генерация резюме ответа и Guard (пост-валидация результата LLM).

### АНП-29. LLM вернула галлюцинацию
В summary упомянут «рейс 999А», которого нет в офферах.
**Guard:** пост-валидация — все упомянутые рейсы/отели должны быть в исходном списке.
Если нет — перегенерировать 1 раз. Если снова — отдать без summary, только структуру.

### АНП-30. LLM вернула ответ на английском
**Guard:** локаль пользователя `ru`. Retry с явной инструкцией.
Если снова — отдать шаблонное summary из данных.

### АНП-31. LLM timeout
Запрос к LLM висит 30 сек. OkHttp кидает timeout.
**Fallback:** шаблонное summary («Найдено N вариантов, лучший — X»).

### АНП-32. LLM вернула слишком длинный текст
Лимит 500 символов. Обрезаем по границе предложения.

### АНП-33. LLM вернула дисклеймер «я не могу гарантировать»
**Guard:** фильтр запрещённых фраз. Retry.
