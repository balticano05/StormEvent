# Анхэппи пути 11–22: Проблемы источников

Падения, таймауты, капчи, смена формата ответов у Atlas, TicketBus, BZD, TicketPro, BelHotel.

### АНП-11. Atlas вернул 500
`AtlasClient` кидает `AtlasClientException`. `AtlasService` оборачивает в `AtlasServiceException`.
`SearchBusesTool` ловит, логирует, возвращает пустой список от Atlas, но результат от TicketBus остаётся.
Пользователь видит только TicketBus. В summary: «Atlas временно недоступен, показаны результаты TicketBus».

### АНП-12. BZD вернул пустую HTML-страницу
`BzdRouteParser` кидает `ParseException`. Service логирует, Tool возвращает пустой список.
Пользователь видит только Atlas/TicketBus.

### АНП-13. Оба автобусных источника упали
Atlas и TicketBus оба вернули ошибку. Tool возвращает пустой список.
Если `TRAIN` тоже пусто — Combiner получает 0 офферов.
**Ответ:** «Ничего не нашлось. Попробуйте изменить дату или направление».

### АНП-14. Таймаут OkHttp (10 сек)
Запрос к Atlas висит. OkHttp кидает `SocketTimeoutException` → `AtlasClientException`.
Tool глотает, возвращает пустой список. Остальные источники продолжают работать параллельно.

### АНП-15. BZD cookie-сессия протухла
Warmup (`GET /ru/`) не выполнился, cookie не сохранился. Запрос к route возвращает 403.
`BzdClientException`. Service пробует warmup ещё раз. Если снова 403 — Tool возвращает пустой список, логирует.

### АНП-16. Atlas SSE-поток оборвался на середине
SSE пришёл с событиями `progress`, потом соединение разорвалось без `done`.
`AtlasSseParser` видит отсутствие `done`, кидает `SseIncompleteException`.
Tool возвращает то, что успел распарсить, с флагом `partial=true`.
В summary: «Показаны частичные результаты Atlas».

### АНП-17. TicketPro вернул 404 на событие
Событие удалено с сайта. `TicketProService` кидает `TicketProServiceException`.
Если запрос был за событием — Tool возвращает пустой список по `EVENT`, но транспорт остаётся.

### АНП-18. BelHotel вернул капчу
HTML содержит форму капчи вместо результатов. Парсер кидает `CaptchaException`.
Tool возвращает пустой список `HOTEL`. Пользователь видит транспорт без отелей.
В summary: «BelHotel временно недоступен».

### АНП-19. Ответ от источника пришёл в новом формате
HTML Atlas изменился, селекторы не находят элементов. Парсер кидает `ParseException: 0 rides found`.
Tool логирует, возвращает пустой. Оповещение в мониторинг (если добавить).

### АНП-20. Источник вернул 0 результатов легитимно
«Минск — Урюпинск 31 декабря». Atlas вернул 200, но `rides=[]`.
Combiner получает пустой список.
**Ответ:** «Рейсов не найдено. Попробуйте другую дату или направление».

### АНП-21. Часть источников вернула мусор
Atlas вернул rides с пустыми полями (`from=null`).
Валидатор `OfferNormalizer` отбрасывает невалидные офферы. Остальные проходят.

### АНП-22. Все три источника вернули >100 результатов
Ranker ограничивает топ-20. Combiner делает top-3 комбо. Пользователь не тонет в выдаче.
