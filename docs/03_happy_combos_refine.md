# Хэппи пути 29–40: Комбо 3+ доменов и Refine

## Комбо 3+ доменов

### HP-29. Выходные в Москве
«Выходные в Москве из Минска, поезд + отель + куда сходить». `TRAIN+HOTEL+EVENT`.
BZD + BelHotel + TicketPro. Три варианта «поезд + отель + два события». Четыре ссылки каждый.

### HP-30. Беловежская пуща
«Хочу в Беловежскую пущу и Брест на 2 дня из Минска». `BUS+HOTEL`, `nearBelovezha=true`.
Atlas (Минск→Брест) + BelHotel (Брест, Каменюки). Комбо с трансфером.

### HP-31. Multi-city
«Маршрут Минск — Витебск — Полоцк — Минск, 3 дня».
Atlas вызывается трижды параллельно. Три сегмента в одной цепочке.

### HP-32. Свободный промпт, агент предложил направления
«Хочу уехать из Минска куда-нибудь на море на неделю в июле, бюджет 500 EUR на двоих».
Агент видит `to=null`, предлагает 2–3 направления из справочника Atlas. После выбора строит комбо.

### HP-20. Славянский базар
«Славянский базар в Витебске, июль». `EVENT+BUS+HOTEL`.
TicketPro даёт список концертов фестиваля, Atlas даёт автобусы, BelHotel даёт отели.
Комбинер строит 3 комбо «автобус + отель + билет». Три ссылки в каждом.

### HP-40. Комбо с обратным рейсом
«Минск — Москва туда-обратно, 10–14 июля, поезд + отель». `TRAIN+HOTEL`, `roundTrip`.
BZD × 2 + BelHotel × 3 ночи. Комбо из двух поездов и отеля.

## Refine

### HP-33. Подешевле
После HP-24: «Подешевле». Refiner: `sort=CHEAPEST`, `budget*=0.7`.
Те же инструменты, новые комбо. Старые в истории сессии.

### HP-34. А если на поезде
После HP-9: «А если на поезде?». Refiner меняет `domains=[TRAIN]`.
Города и дата сохраняются. Только BZD.

### HP-35. На день позже
«На день позже». Refiner: `dateFrom+=1`, `dateTo+=1`.
Те же инструменты. Новые результаты.

### HP-36. Только ссылки
«Просто дай ссылки Минск — Брест на завтра». `linksOnly=true`.
Combiner пропускает ранжирование и summary, отдаёт плоский список URL'ов.

### HP-37. Кэш-хит
Через 5 минут после HP-1: «Те же автобусы, только на 16 июня».
Session store видит предыдущий интент, Refiner меняет только дату. Без уточнений, сразу результат.

### HP-38. Уточнение по времени суток
«Автобус Минск — Варшава 10 июля». `missing={window}`.
Clarifier: «Утренние, дневные или ночные?» Пользователь: «Ночные».
`SearchBusesTool` с `window=NIGHT`. 3 рейса.

### HP-39. Не хватает даты — один вопрос
«Хочу на поезде из Минска в Брест». `missing={date}`.
Clarifier: «На какую дату?» Пользователь: «15 июня». Merge. BZD. Расписание.
