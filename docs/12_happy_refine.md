# Хэппи пути 41–68: Refine

Refine всегда мержит в старый интент, сохраняя контекст сессии. Отдельные правила
и анхэппи-случаи — в [`14_unhappy_refine.md`](14_unhappy_refine.md).

### HP-41. «Ещё варианты»
После выдачи 5 комбо пользователь пишет «Ещё». Refiner: `offset += 5`.
Tool возвращает те же офферы, но Combiner сдвигает окно. Показывает следующие 5.
Если офферов меньше — «Больше нет».

### HP-42. «Только с Wi-Fi»
После автобусов: «Только с Wi-Fi». Refiner: `prefs.wifi=true`.
Фильтр на `Offer.details` по amenities. Combiner прогоняет заново. Меньше вариантов, но релевантные.

### HP-43. «Убрать пересадки»
«Убрать пересадки». Refiner: `directOnly=true`.
Combiner отбрасывает цепочки из 2+ сегментов. Остаются прямые.

### HP-44. «Добавь отель»
После транспорта: «Добавь отель». Refiner: `domains += HOTEL`.
Транспортные офферы уже в сессии, дёргается только BelHotel. Combiner склеивает.

### HP-45. «Убери отель»
Обратное: `domains -= HOTEL`. Combiner пересобирает без HOTEL-легов.

### HP-46. «Только Atlas»
«Покажи только Atlas». Refiner: `sources=[atlasbus]`.
Tool фильтрует офферы по source. Combiner строит из подмножества.

### HP-47. «Раньше 10 утра»
«Раньше 10 утра». Refiner: `windowBefore=10:00`.
Фильтр по `departAt`. Combiner прогоняет заново.

### HP-48. «После 18:00»
Аналогично `windowAfter=18:00`.

### HP-49. «Поездом, не автобусом»
Refiner: `domains=[TRAIN]`. Сохраняет `from/to/date`. Дёргает BZD.

### HP-50. «Обратно тоже»
После one-way: «Обратно тоже». Refiner: `roundTrip=true`.
Добавляет второй сегмент, `dateTo = dateFrom + 2д`. Дёргает Tool на обратное направление.

### HP-51. «На 2 дня дольше»
«На 2 дня дольше». Refiner: `dateTo += 2`. Combiner пересчитывает ночи отеля.

### HP-52. «Бюджет 300 BYN»
«Бюджет 300». Refiner: `budgetMax=300`. Combiner отбрасывает дорогие комбо.

### HP-53. «Двое взрослых и ребёнок»
«Ещё ребёнок». Refiner: `children += 1`.
Валидатор пропускает. Tool передаёт в источник (если поддерживается).

### HP-54. «Сравни с поездом»
После автобусов: «Сравни с поездом». Refiner: `domains += TRAIN`, `prefs.compare=true`.
BZD дёргается, Combiner группирует BUS vs TRAIN по времени отправления.

### HP-55. «Покажи на карте»
Если добавить geo: «Покажи на карте». Refiner: `prefs.geoView=true`.
Combiner добавляет координаты отелей/вокзалов.

### HP-56. «Только 4 звезды»
После отелей: «Только 4 звезды». Refiner: `hotelRating=4`.
BelHotel фильтрует или Combiner отбрасывает.

### HP-57. «Завтра»
После запроса на конкретную дату: «Завтра». Refiner: `dateFrom=tomorrow`, `dateTo=tomorrow`.
Дёргает те же Tool.

### HP-58. «На выходные»
«На выходные». Refiner вычисляет ближайшие сб/вс. Дёргает Tool.

### HP-59. «Покажи от TicketBus»
«Только TicketBus». Refiner: `sources=[ticketbus]`. Аналогично HP-46.

### HP-60. «Самый быстрый»
После CHEAPEST: «Самый быстрый». Refiner: `sort=FASTEST`. Ranker пересортировывает.

### HP-61. «Убери ночные»
Refiner: `windowExclude=NIGHT`. Combiner отбрасывает 22:00–06:00.

### HP-62. «Только прямые поезда»
Refiner: `directOnly=true`, `domains=[TRAIN]`. BZD-фильтр.

### HP-63. «Добавь концерт вечером»
После транспорта: «Добавь концерт вечером». Refiner: `domains += EVENT`, `window=EVENING`.
TicketPro дёргается, Combiner подбирает событие, привязанное к прибытию.

### HP-64. «Начнём заново»
«Начнём заново». Session очищает intent, но сохраняет историю сообщений для контекста.
Агент: «Ок, что ищем?»

### HP-65. «Покажи предыдущий вариант»
«Покажи предыдущий». Session отдаёт предыдущий снапшот результатов из истории. Без новых вызовов.

### HP-66. «Оставь только вариант 2»
«Оставь только вариант 2». Refiner: `selectedOption=2`.
Сессия фиксирует выбор, дальнейшие refine применяются только к нему.

### HP-67. «Сколько всего нашлось?»
Мета-вопрос без изменения интента. Session отвечает: «Нашлось 47 офферов из 3 источников, построено 12 комбо».

### HP-68. «Откуда данные?»
Агент отвечает списком источников, использованных в последнем поиске.

### HP-68 (доп.). Refine с новым городом
После «Минск — Брест»: «А из Гомеля». Refiner: `from=Гомель`.
Tool дёргается заново для Гомель→Брест.
