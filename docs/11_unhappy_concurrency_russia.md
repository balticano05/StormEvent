### АНП-57. Deadlock в session store
Два запроса на одну сессию одновременно. Session store использует
`ConcurrentHashMap` + `synchronized` по `sessionId`. Второй ждёт.
Если первый висит 30 сек — таймаут, отказ.

### АНП-58. Утечка потоков
~~`Executors.newVirtualThreadPerTaskExecutor()` не закрыт try-with-resources.~~ — **[ОТМЕНЕНО]** (ADR-VL-15: пулов источников не создаём; try-with-resources в `Application` / `@PreDestroy`).
[ВЛ] Пул источников не создаётся; все закрываемые ресурсы (планировщики, `DataSource`) — через `@PreDestroy`/try-with-resources в `Application`.

## Специфика РФ

### АНП-59. BZD не покрывает маршрут внутри РФ
«Москва — Казань». BZD — белорусский сайт, международные рейсы. Внутри РФ — не отдаёт.
**Ответ:** «Внутри РФ через BZD не ищется. Попробуйте РЖД напрямую» — но это уже за рамками текущих источников.

### АНП-60. Atlas не работает на маршрутах внутри РФ
«Москва — Питер». AtlasBus — белорусский. Возможно 0 результатов.
**Fallback:** «Показать только белорусские направления?»

### АНП-61. Санкционные ограничения
Оплата картой РФ на белорусских сайтах. Ссылка есть, но оплата не пройдёт.
Агент не отвечает за оплату — только отдаёт ссылку. Но в summary можно добавить дисклеймер.

### АНП-62. Языковая проблема
Пользователь пишет «Минск — Масква». LLM нормализует в «Москва».
Если нет — suggest не находит.
Clarifier: «Вы имели в виду Москва?»
