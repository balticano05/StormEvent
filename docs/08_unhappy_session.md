# Анхэппи пути 34–38: Сессия и refine

Session store, Refiner, отмена и конкурентность по одной сессии.

### АНП-34. Refine без предыдущего интента
Пользователь пишет «Подешевле» в новой сессии. Session store пуст.
**Ответ:** «Уточните, что искать — тогда смогу подешевле».

### АНП-35. Refine противоречит старому интенту
Было «поезд Минск — Москва», пользователь пишет «а если из Бреста».
Refiner мержит, но `from=Брест` теперь. Валидатор: `from ≠ старый from` → это не refine, а новый поиск.
Агент подтверждает: «Понял, ищем из Бреста вместо Минска?» Пользователь: «Да». Новый поиск.

### АНП-36. Session TTL истёк
Пользователь возвращается через 2 часа. Сессия удалена по TTL.
**Ответ:** «Сессия истекла, начнём заново. Что ищем?»

### АНП-37. Пользователь отправил два сообщения подряд
Второе пришло, пока агент ещё обрабатывал первое. Session блокирует по `sessionId`.
Второе ждёт. Или отклоняется с «Подождите, обрабатываю предыдущий запрос».

### АНП-38. Пользователь написал «отмена» в середине цикла
Флаг `cancel`. Текущий LLM-вызов прерывается, session очищается.
